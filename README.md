# SRE Portfolio – Infrastructure Dashboard

A production-grade portfolio website designed as an internal SRE platform. Built with Next.js 14, TypeScript, and Tailwind CSS.

**Live:** 

---

## 🚀 Quick Start

```bash
npm install
npm run dev
# Open http://localhost:3000
# Press ⌘K for command palette
```

## 📚 Tech Stack

- Next.js 14 (App Router)
- TypeScript (strict mode)
- Tailwind CSS (dark-first)

## 🎯 Features

- 8 SRE-named routes
- Dark-first design (Kubernetes aesthetic)
- ⌘K command palette
- 22 skills, 3 jobs, 2 projects
- Responsive design
- Resume download
